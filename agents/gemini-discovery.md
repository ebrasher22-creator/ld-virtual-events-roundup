## Exact intake contract
Return only a JSON array, without Markdown fences, comments, trailing commas, or an enclosing `events` object. Use `discovered_by: ["gemini"]` (lowercase). Use `event_format` from `virtual`, `hybrid`, `in_person`, `on_demand`; `price_type` from `free`, `paid`, `unknown`. Use an IANA timezone such as `America/Chicago`, never `CST` or `Central Time`. Timestamps need seconds plus an explicit offset (e.g. `2026-12-01T12:00:00-06:00`) or UTC `Z`. Nonzero local offsets must match the named zone, including DST.

Every record needs all 16 required fields listed in the schema. `audience`, `topics`, `source_urls`, `discovered_by`, and `evidence` are nonempty arrays. Each evidence object has only `claim`, `source_url`, `excerpt`, all nonempty text. URLs must be absolute HTTP(S), with no placeholders. Unknown price is `unknown`; unknown numeric cost is null or omitted. Omit optional editorial/canonical fields; the pipeline assigns them. Null is allowed only where the schema explicitly permits it. Do not include currency symbols in numeric cost; document the currency in the evidence excerpt if relevant.

If the confirmed start time, IANA timezone or registration destination cannot be established, leave that lead outside machine intake and report it separately for human follow-up; do not fabricate required fields. The source registry is not an allowlist. Its null URLs need independent discovery; it is not evidence of active event publication. Consult `tests/fixtures/gemini.json` for structure only (all fixture events are fictional).
