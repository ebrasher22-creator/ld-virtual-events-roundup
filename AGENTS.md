# Engineering rules
Preserve raw intake and provenance. Use Python 3.11+ standard library; no paid AI calls. Never equate model evidence with independent verification. Keep deterministic ingestion and conflict quarantine. Review changes on a feature branch. Never merge, deploy or publish to LinkedIn without explicit approval. Run python3 -m unittest discover -s tests -v and the isolated smoke test. Config files are JSON-compatible YAML; use json.load without extra dependencies.

Owner approvals may use detailed human observations or an exact source-preserved explicit owner attestation. Never invent claim observations or source-check timestamps. Keep exact-record/source fingerprints current. Pricing is optional; do not infer free admission. Wednesday preparation reads approvals and never grants them. Recurring preparation remains inactive until owner activation.

ChatGPT Work is the primary creative editor; Python remains factual/eligibility authority and fallback. Validate every returned caption against current editorial input. Mechanical PASS never means semantic or publication approval. No Work scheduling or unattended write capability is assumed.
