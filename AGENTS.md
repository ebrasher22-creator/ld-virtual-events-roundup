# Engineering rules
Preserve raw intake and provenance. Use Python 3.11+ standard library; no paid AI calls. Never equate model evidence with independent verification. Keep deterministic ingestion and conflict quarantine. Review changes on a feature branch. Never merge, deploy or publish to LinkedIn without explicit approval. Run python3 -m unittest discover -s tests -v and the isolated smoke test. Config files are JSON-compatible YAML; use json.load without extra dependencies.
