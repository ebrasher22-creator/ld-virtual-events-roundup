# Owner-mediated editorial draft intake

Save the exact `work-submission.json` returned by ChatGPT Work in a week-specific directory here on a review branch. Never add approval statements or executable code to a draft. Local/Actions validation parses JSON only; successful mechanical validation leaves semantic and publication approval pending.

`RW49/supervised-example.json` is a supervised return-contract example authored in the Codex implementation session. It is not a scheduled Work result and has not been approved for publication. It exercises the exact same immutable input, validator and manual Actions intake that a real Work response will use.
